# ⚡ SkillGap AI

**Upload your resume. Get a personalized career report in seconds.**

Most job seekers don't know why they're getting rejected. They apply to dozens of roles without knowing whether they're qualified, what skills they're missing, or what to improve next.

SkillGap AI analyzes your resume and location, then generates a personalized career report showing:

* Suitable job roles
* Skill gaps
* Learning roadmap
* Local job suggestions
* Career advice
* Job readiness score

No forms. No quizzes. Just upload your PDF and get actionable feedback.

---

## Why I Built This

Many graduates struggle to understand where they stand in the job market. Career guidance can be expensive, generic, or difficult to access.

SkillGap AI helps bridge that gap by analyzing a real resume and providing practical recommendations tailored to the user's current skills and experience.

---

## Features

* Resume PDF analysis
* Recommended job roles
* Skill gap detection
* Personalized learning path
* Location-based job suggestions
* AI-generated career advice
* Job readiness score (0–100)

---

## How It Works

```text
Resume PDF
    ↓
PyPDF2 extracts text
    ↓
Resume + Location
    ↓
Claude 3.5 Haiku
    ↓
Career Report
    ↓
Reflex UI
```

## Run Locally

```bash
git clone https://github.com/YOUR_USERNAME/skillgap_ai.git
cd skillgap_ai

python -m venv venv
source venv/bin/activate

pip install -r requirements.txt

reflex init
reflex run
```

Create a `.env` file:

```env
OPENROUTER_API_KEY=your_api_key
```

## Limitations

* Scanned PDFs are not supported
* AI-generated advice may not always be accurate
* Job suggestions are generated by the model and are not pulled from live job listings
* No user accounts or saved history
